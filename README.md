# CampuRecover

Smart AI-Powered Lost & Found Portal for Colleges

## Technologies Used

- HTML
- CSS
- Bootstrap
- JavaScript
- PHP PDO
- Python
- MySQL
- XAMPP

---

## Features

- User Authentication
- Lost Item Reporting
- Found Item Reporting
- Smart Search System
- AI Matching
- QR Recovery
- OCR Support
- Admin Dashboard
- Live Chat
- Notifications
- Responsive UI

---

## Setup Instructions

### Step 1
Copy project folder to:

C:/xampp/htdocs/CampuRecover

---

### Step 2
Start:
- Apache
- MySQL

---

### Step 3
Create Database:

campurecover

Import:

database/tracehive.sql

---

### Step 4
Run Project:

http://localhost/CampuRecover
